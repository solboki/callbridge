# Journal des versions

## 1.3.0 (2 novembre 2026)

Première version publiée. Le style « téléphonie » expérimental de la version 1.2.0 est retiré : Garmin Connect ne l'utilisait pas pour choisir l'icône. Les boutons « Style des appels » et « Tester un appel entrant » disparaissent avec lui.

## 1.2.0

Le fichier APK porte son numéro de version dans son nom. Essai d'une présentation des appels imitant les applications de téléphonie d'Android, retiré dans la version suivante.

## 1.1.0

Le nom de l'appelant s'affiche pour un appel entrant. Il est cherché d'abord dans le carnet d'adresses de Sailfish, puis dans les contacts du conteneur Android.

## 1.0.3

Le service reconnaît les SMS et les appels manqués par le nom de l'application qui les publie. Sailfish OS 5 publie en effet les SMS sans catégorie, sous le nom « Messages ».

## 1.0.2

L'application indique si Android bloque ses notifications et ouvre directement le réglage correspondant. Chaque bouton confirme son action par un message.

## 1.0.1

L'application vise l'API 25 au lieu de l'API 23, car Android 15 refuse d'installer les applications qui visent une version inférieure à l'API 24.

## 1.0.0

Première version : SMS, appels manqués, appels entrants et catégories de notifications au choix.
